# Rick and Morty Characters App

Мобильное приложение на Flutter для просмотра персонажей мультсериала "Рик и Морти".  
Позволяет просматривать список персонажей, добавлять их в избранное и работать с приложением оффлайн.

---

## Функционал

- Главный экран:
  - Список персонажей в виде карточек.
  - Каждая карточка содержит изображение, имя и статус.
  - Кнопка "звездочка" для добавления в избранное.
- Экран "Избранное":
  - Отображение избранных персонажей.
  - Возможность удаления персонажей из избранного.
- Поддержка двух вариантов лэйаута (2 или 3 колонки).
- Пагинация: подгрузка новых персонажей при скролле.
- Кеширование: данные сохраняются локально через Hive.
- Навигация через BottomNavigationBar.

---

## Используемые технологии

- **Flutter** — UI и логика приложения.
- **Dio** — для REST API-запросов.
- **BLoC / Cubit (flutter_bloc)** — управление состоянием.
- **GetIt** — dependency injection.
- **Hive / Hive Flutter** — локальное хранение данных и кеширование.
- **cached_network_image** — оптимизированная загрузка изображений.
- **connectivity_plus** — проверка интернет-соединения.
- **Hive Generator + build_runner** — генерация адаптеров для моделей.

## Установка и запуск

1. Клонировать репозиторий:
git clone https://github.com/McBombo4ka/rick_and_morty_app.git
   
Перейти в директорию проекта:
cd rick_and_morty_app

Установить зависимости:
flutter pub get

Запустить приложение:
flutter run
